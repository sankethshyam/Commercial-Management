# Sanketh Shyam — Professional Profile

A dependency-free, responsive single-page website for Sanketh Shyam's Commercial Sourcing & Procurement professional practice.

## Run locally

```bash
npm start
```

The site is then served at `http://localhost:4173` in a normal local development environment.

## Edit content

- Update the capability cards, process steps, practical-work templates and principles in `site-data.js`.
- Update the introductory and contact copy in `index.html`.
- Replace the `example.com` canonical and Open Graph URLs in `index.html` once a production domain is available.
- Replace case-study placeholder content only with approved, factual information.

## Deploy

This is a static site. Upload the project files to any static web host, with `index.html` at the web root.
